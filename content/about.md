# About

This is an index, not a blog. The posts live where they were written:

- **dev log** — <https://shaoyanji.is-a.dev>, notes on infrastructure and tooling.
- **mataroa** — <https://jisifu.mataroa.blog>, longer pieces.
- **envs.net** — <https://jisifu.envs.net>, a shell page and twtxt.
- **serv00** — <https://jisifu.serv00.net>, FreeBSD experiments.
- **dragoncourt** — <https://dragoncourt.alwaysdata.net>, PHP and Wasm on shared hosting.

The repositories are on [GitHub](https://github.com/shaoyanji). Mail:
[mail@shaoyanji.is-a.dev](mailto:mail@shaoyanji.is-a.dev).

Everything here is built with [nixstix](https://github.com/shaoyanji/nixstix) and
published by a GitHub Actions workflow on every push to `main`. The recent-writing
list is read from the sources' feeds before the build, so this page cannot drift
from them.

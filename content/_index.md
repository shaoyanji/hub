I keep a small fleet of machines and write about what it takes to run them:
a Nix configuration that spans NixOS, macOS and Home Manager; an email archive
that answers questions about its own mail; agents that read, file and report so
a person does not have to.

The writing never lived in one place. This page is the index of it — the five
homes it has accumulated, the posts as they are published, and the repositories
behind them.
